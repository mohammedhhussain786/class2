Part A — Aptitude

Percentages

1What percentage means

Percent means per hundred — out of 100. Whenever the % symbol appears, read it as “out of 100”.

25% = 25100 = 14

2The basic formula

Percentage = PartWhole × 100

Example

A class has 40 students and 20 are present. What percentage are present?

20 ÷ 40 × 100 = 50%

3Percentage to fraction

These ten conversions should become instant. Most speed in an aptitude paper comes from recognising the fraction instead of multiplying.

%10202530405060758090100
Fraction1/101/51/43/102/51/23/53/44/59/101

Example

Find 25% of 800. Since 25% is one quarter, divide.

800 ÷ 4 = 200

4Fraction to percentage

Percentage = NumeratorDenominator × 100

3/5 × 100 = 60% · 1/4 × 100 = 25%

5Decimals both ways

Decimal to percentage, multiply by 100. Percentage to decimal, divide by 100.

0.25 → 25% · 0.75 → 75% · 35% → 0.35

6Finding a percentage of a number

This is the single most common question type in the paper.

Example — the long way

20% of 500 = 20/100 × 500 = 100

The same thing, faster

20% is one fifth, so 500 ÷ 5 = 100

8“X is what percentage of Y?”

20 of 80 → 20/80 × 100 = 25% · 45 of 90 → 50%

9Finding the whole

When a percentage of an unknown number is given, work back to 100%.

Example

20% of a number is 50. Find the number.

20/100 × x = 50 → x = 250

Shortcut: if 20% = 50, then 100% = 50 × 100 ÷ 20 = 250

10Percentage increase and decrease

Increase % = IncreaseOriginal × 100 Decrease % = DecreaseOriginal × 100

Increase

Salary ₹10,000 → ₹12,000. Increase is 2,000.

2000 / 10000 × 100 = 20% increase

Decrease

Price ₹800 → ₹600. Decrease is 200.

200 / 800 × 100 = 25% decrease

The trap examiners rely on

Change is always measured against the original value, so the two directions are not the same percentage.

100 → 120 is a 20% increase. 120 → 100 is a 16.67% decrease.

11Successive changes

A 20% rise followed by a 10% rise is not 30%. The second change acts on the already-increased value.

Net change = a + b + ab100 → 20 + 10 + 2 = 32%

Check it on ₹100

₹100 → ₹120 → ₹132. That is a 32% increase, exactly as the formula says.

12Equal increase then decrease

Up 20% then down 20% does not return you to where you started.

₹100 → ₹120 → take away 20% of 120, which is ₹24 → ₹96.

Net result: 4% decrease

Net decrease = x²100 → 20²100 = 4%

Part B — Reasoning

Coding–Decoding

A word, letter or number is changed according to a hidden rule. The work is to discover the rule from the example given, then apply it to something else.

Example

CAT → DBU

C→D, A→B, T→U. Every letter moved one position forward.

2Shift coding — forward and backward

RuleCAT becomesWhy
+1DBUeach letter one step forward
+2ECVeach letter two steps forward
−1BZSeach letter one step back; A wraps to Z

Watch the wrap

A moving back becomes Z, and Z moving forward becomes A. The alphabet is a circle, not a line.

3Number coding

Replace each letter with its position.

CAT = 3-1-20 · DOG = 4-15-7 · PEN = 16-5-14

4Reverse alphabet coding

Here A = 26, B = 25, and so on down to Z = 1. You never need to memorise a second list — subtract from 27.

Reverse position = 27 − forward position C = 27 − 3 = 24

CAT = 24-26-7

5Word coding by relationship

Sometimes the whole word maps to a single number, and the rule is a relationship rather than a shift.

Example

If CAT = 24 and DOG = 26, the rule is the sum of alphabet positions.

C+A+T = 3+1+20 = 24 · D+O+G = 4+15+7 = 26

6Coding from a given example

Example

If APPLE → BQQMF, find the code for MANGO.

A→B, P→Q, L→M, E→F, so the rule is +1. Applying it:

MANGO → NBOHP

7Coding through statements

Two coded statements are given and you find the code for one word by matching what they share.

Example

“red blue green” = “ka la ma” and “blue yellow” = “la pa”. What is the code for blue?

The only common word is blue; the only common code is la.

blue = la

8A method that stops the guessing

Run through this order every time rather than testing rules at random.

  • Write out A = 1 to Z = 26 in the margin.
  • Place the original and the coded letters side by side.
  • Test +1, then +2 or +3.
  • Test −1, then −2.
  • Test the reverse alphabet.
  • Test numerical values and their sum.
  • If none fit, look for a word relationship instead of a letter rule.
